# 📋 行動秘書

每日待辦提醒網頁，手機與電腦都能用。

## 功能
- **未完成自動延續**：今天沒做完的事，明天、後天會一直出現在「今日待辦」，直到你勾選完成。
- **顏色區分狀態**
  - 🔵 藍色：今天新增、尚未完成
  - 🟠 橘色：之前沒做完，延續到今天
  - 🔴 紅色：超過截止日，或已延續 3 天以上
  - 🟢 綠色：已完成
- **每日完成紀錄**：依日期列出每一天完成的事項。
- **全部紀錄**：依建立日期查看每天的完成率。
- **提醒**：每日固定時間提醒還有幾項沒做完；每個事項也可以設定提醒時間（需允許瀏覽器通知）。
- 截止日、重要程度（高／中／低）、備註、編輯、刪除（可復原）。
- 備份匯出／匯入，可把資料搬到另一台裝置。
- 可「加入主畫面」當 App 使用，離線也能開。

## 使用方式
開啟 GitHub Pages 網址即可使用。
- **iPhone**：Safari 開啟 → 分享 → 「加入主畫面」，從主畫面圖示開啟才能收到通知（iOS 16.4 以上）。
- **Android / 電腦**：Chrome 開啟，網址列可選「安裝」。

## 注意
- 資料存在各裝置瀏覽器裡（localStorage），手機和電腦的資料不會自動同步，可用「設定 → 匯出／匯入」搬移。
- 通知在 App 或分頁開著（或在背景剛被開過）時最可靠；完全關閉時，下次打開會立即提醒未完成事項。

## 開發
純靜態網頁，無需建置：`index.html`、`sw.js`、`manifest.webmanifest`。
